# 트릭컬 와일드카드 계산기 데이터 연동기 — 개인정보·보안 안내

이 확장 프로그램은 **트릭컬노트에서 내 카드 레벨과 사도 레벨을 계산기로 옮겨 주는 일**만 합니다.
(비공식 팬 제작 도구이며 게임사·트릭컬노트와 무관합니다.)

## 수집하는 정보 (전부 내 브라우저 안에만 저장)
| 항목 | 내용 |
|---|---|
| 카드 | 카드 ID, 레벨, 보유 장수, 한계돌파 수치 |
| 사도 | 사도 ID, 레벨, 랭크, 등급, 어사이드 등급, 스킬 레벨, 어사이드 한계돌파 |

## 수집하지 않는 정보
- 닉네임, 유저 ID, 친구 코드, 계정 레벨 등 **프로필 정보**
- 로그인 정보, 쿠키, 토큰, 비밀번호, 결제 정보
- 요청 주소의 쿼리스트링(주소에서 `?` 뒤는 버립니다)
- 방문 기록, 다른 사이트 데이터

## 데이터가 가는 곳
- **외부 서버로 전송하지 않습니다.** 이 확장 프로그램은 자체 네트워크 요청을 하지 않습니다.
- 추출한 정보는 확장 프로그램 저장소(`chrome.storage.local`)와 계산기 페이지의 브라우저 저장소(`localStorage`)에만 저장됩니다.
- 분석 도구, 광고, 추적 코드가 없습니다.

## 동작 방식
1. 트릭컬노트 페이지가 **이미 받아온 응답**을 읽기만 합니다(응답을 복제해서 읽으며, 요청이나 응답을 바꾸지 않습니다).
2. 응답에 카드·사도 목록이 있을 때만 위 항목만 골라냅니다.
3. 골라낸 값은 형식과 범위를 검증한 뒤 저장하고, 계산기 페이지를 열었을 때 그 페이지로만 전달합니다.

## 권한을 요구하는 이유
| 권한 | 이유 |
|---|---|
| `storage` | 추출한 카드·사도 정보를 내 브라우저에 보관 |
| `note.trickcal.com` 접근 | 내 카드·사도 응답을 읽기 위해 |
| `antarctichare.github.io/trickal` 접근 | 계산기 페이지에 내 정보를 전달하기 위해 |

## 직접 확인하는 방법
- 코드는 세 파일(`hook_main.js`, `bridge_isolated.js`, `manifest.json`)뿐이며 압축·난독화하지 않았습니다. 설치 전에 열어서 읽어 볼 수 있습니다.
- 개발자 도구(F12) → Network 탭에서 확장 프로그램이 보내는 요청이 없는 것을 확인할 수 있습니다.

## 삭제
- 계산기의 **「🗑️ 내 데이터 초기화」** 버튼: 확장 프로그램 저장분과 계산기 저장분을 모두 삭제합니다.
- 확장 프로그램을 제거하면 저장 데이터도 함께 삭제됩니다.

## 자주 묻는 질문
**내 계정을 탈취하거나 조작할 수 있나요?**
계정 정보(로그인 정보·쿠키·토큰)를 읽어 저장하지 않으며, 게임/사이트로 요청을 보내는 기능도 없습니다. 읽기 전용입니다.

**"사이트의 데이터를 읽고 변경" 경고가 뜨는 이유는?**
Chrome이 특정 사이트에서 동작하는 모든 확장 프로그램에 표시하는 공통 문구입니다. 이 확장 프로그램은 위 두 주소에서만 동작합니다.

**'data 응답 직접 붙여넣기'를 쓰면 개인정보가 저장되나요?**
붙여넣은 응답에는 닉네임·친구 코드가 포함되어 있지만, 카드·사도 정보만 추출하고 입력창은 적용 즉시 비워집니다. 확장 프로그램을 쓰면 이 과정 자체가 필요 없습니다.
